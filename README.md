# Pabu

Pabu 是可自行部署的导航首页，支持访客本地配置、管理员导航管理、口令同步空间与临时加密文本分享。

## 能力

- 分类和链接管理、搜索引擎与视觉偏好
- 访客配置保存在浏览器 IndexedDB，管理员个人导航与站点默认首页分别保存
- 通过口令创建或连接同步空间，支持设备授权与管理员邀请码、空间治理
- 使用浏览器加密的临时文本分享，可设 PIN 和有效期
- 管理员登录保护个人导航及站点设置

同步邀请码由管理员在「管理」面板生成。邀请码一次性使用，有效期 48 小时，不提供开放注册。知晓同步口令的人可以读写对应空间，请妥善保管。导航同步数据由服务端保存并可读取，不提供端到端加密。临时文本分享单独使用浏览器加密，服务端只暂存密文。

## 部署

需要 Node.js 22 或更新版本。安装依赖后启动：

```sh
npm ci
npm start
```

默认监听 `127.0.0.1:4001`。默认弱密码 `admin123` 首次登录后会要求设置强密码。公网部署应使用 HTTPS 反向代理，并将 `COOKIE_SECURE=true` 保持开启。

可复制 `.env.example` 为 `.env` 设置监听地址、端口、HTTPS 和日志路径。完整选项见 `server-config.example.json`。服务将配置和会话保存在 `config.json` 与 `pabu.db`，数据库和凭据文件由服务限制为仅当前用户可读写。

## 本地开发

```sh
npm start
node --test tests/*.test.js
```

Pabu 从 Nav Sylph 拆分为独立项目，版本从 `0.1.0` 开始。邀请码策略沿用一次性邀请码，由管理员治理同步空间。
