# Pabu导航

Pabu导航 是可自行部署的导航首页，核心功能是导航编辑、多端同步与文本分享。

## 核心功能

- **导航编辑**：增删分类和链接，管理搜索引擎、图标与视觉主题。访客配置保存在浏览器 IndexedDB；管理员在 `/admin` 的一比一画布中直接编辑站点默认导航，保存后对未自定义的访客生效。
- **多端同步**：通过口令创建或连接同步空间，导航修改自动同步。管理员可开启或关闭邀请限制，开启时需要一次性邀请码，关闭后输入口令即可创建。支持设备授权和空间治理。
- **文本分享**：浏览器生成随机取件码并加密内容，取件码本身是解密密钥，服务端只保存密文和散列 ID。可设 PIN 和有效期，通过链接、二维码或分组取件码分享。
- **文件分享**：搜索框输入 `》` 或点击搜索框下方的「输入》分享文件」选择文件，生成 5 位数字取件码。接收方在搜索框输入取件码后，双方通过 WebRTC 直连传输，文件不经过服务器保存，并显示 4 位确认码供双方核对。直连失败时可改用服务器中转：浏览器分片加密后上传，可设 PIN 和有效期，下载一次后自动删除，默认单文件上限 64 MiB、服务端总容量 256 MiB。搜索框会把任意 5 位数字当作实时取件码；需要搜索 5 位数字时先按 Esc 取消识别。

## 管理

- 首页始终显示当前用户自己的本地导航，管理员登录只获得管理权限，不切换首页
- 管理后台位于 `/admin`，站点默认导航在一比一画布中直接编辑和发布
- 管理员可编辑同步空间备注、停用、删除和重置设备，不读取空间正文或设备凭据
- 用户端不提供删除云端空间，避免误删其他设备仍在使用的共享内容；用户可停止同步或撤销本设备

管理员可在「管理」面板决定创建同步空间是否需要邀请码。开启邀请限制时，邀请码一次性使用，有效期 48 小时；关闭后，访客输入口令即可创建空间，已有邀请码保留，重新开启即恢复限制。Pabu 不提供开放注册。知晓同步口令的人可以读写对应空间，请妥善保管。导航同步数据由服务端保存并可读取，不提供端到端加密。临时文本与文件分享单独使用浏览器加密，服务端只暂存密文；文件中转的密文分片保存在 `transfers/`，元数据在内存中，服务重启后清空。实时直连的文件不经过服务器，服务端只转发 WebRTC 信令，5 位取件码同一时间只允许一个接收方，成功传输后失效，并限制尝试次数。

## 部署

需要 Node.js 22 或更新版本。建议使用管理脚本安装：

```sh
curl -fsSL https://raw.githubusercontent.com/mh567/pabu/main/pabu.sh | bash
```

默认安装到 `~/pabu` 并监听 `127.0.0.1:4001`。指定目录：

```sh
curl -fsSL https://raw.githubusercontent.com/mh567/pabu/main/pabu.sh | PABU_DIR=/opt/pabu bash
```

```sh
cd ~/pabu
./pabu.sh start      # 启动
./pabu.sh status     # 状态与健康检查
./pabu.sh update     # 更新，保留配置和数据库
sudo ./pabu.sh enable  # 开机自启（systemd）
```

默认弱密码 `admin123` 首次登录后会要求设置强密码。公网部署应使用 HTTPS 反向代理，并将 `COOKIE_SECURE=true` 保持开启。

可复制 `.env.example` 为 `.env` 设置监听地址、端口、HTTPS 和日志路径。完整选项见 `server-config.example.json`。服务将配置和会话保存在 `config.json` 与 `pabu.db`，数据库和凭据文件由服务限制为仅当前用户可读写。完整说明见 `DEPLOYMENT.md`。

## 本地开发

```sh
npm start
node --test tests/*.test.js
```

Pabu 从 Habu 拆分为独立项目，版本从 `0.1.0` 开始。创建空间的邀请限制由管理员开关控制。
