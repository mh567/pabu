# Pabu 架构

Pabu 是从 Habu 独立拆分的轻量导航服务，核心功能是导航编辑、多端同步与文本分享。Node.js 22 运行 Express 服务，静态前端由同一服务提供。

## 导航与存储

- `public/navigation-schema.js` 在浏览器和服务端共同校验导航结构。
- 普通访客导航保存在 IndexedDB `pabu-personal`；站点导航保存在 SQLite 的单一 `site` 文档，管理员在 `/admin` 的一比一画布中直接编辑，保存即发布。首页始终使用用户本地导航，管理员会话不改变首页数据。
- 管理会话、站点导航版本、同步空间、设备授权、邀请码和幂等回执共用 `pabu.db`。
- SQLite 保留上游历史迁移步骤以维持编号，新增尾部迁移删除不适用的模块缓存、监控、备忘、待办、时间线和恢复记录表。Pabu 数据库仅保留会话、导航、同步空间及治理配置相关表。
- 管理会话 Cookie 为 `pabu_session`。管理写请求校验会话、同源信息和 `X-Pabu-Request` 请求头。
- 管理后台通过独立路径 `/admin` 进入，复用同一套前端资源并以整页呈现，首页不展示管理入口。管理接口仍由 `requireAdmin` 保护。

## 口令同步

口令不上传。浏览器派生连接证明，服务端以散列值定位空间，再签发设备令牌。同步导航数据保存在服务端，服务端可读取数据，不提供端到端加密。创建空间是否消耗邀请码由管理员开关控制：开启时使用一次性邀请码，关闭时只凭口令即可创建。Pabu 不提供开放注册。管理端展示空间状态、大小、版本、备注和设备数，可以编辑备注、停用、删除和重置设备，不读取空间正文或设备凭据。

同步内容包括导航及搜索引擎配置。设备凭据保存在浏览器 IndexedDB，服务端的空间数据存于 SQLite。同步空间由管理员控制暂停、停用和删除，用户端只提供停止同步与撤销本设备，避免误删共享内容。

## 临时分享

分享正文由浏览器使用 Web Crypto 加密后交给服务端，服务端只临时保存密文。PIN、有效期、取件次数和总容量由服务端校验。分享数据保存在内存，服务重启即清空。

文本分享 v2 的取件码由浏览器生成，是 128 位随机密钥，按 26 位 base32 分组展示。服务端只接收它的 SHA-256 散列前 16 字节作为记录 ID，解密密钥放在分享链接的 URL fragment 里，不会发送给服务端。创建时浏览器再派生一个域分离的取件证明，服务端只存证明；取件必须同时携带它，所以只有路径 ID 的人既取不走内容，也无法通过错误 PIN 把记录试到销毁。取件页从 fragment 读回密钥，先校验散列 ID 与证明，再发起取件；缺少或损坏 fragment 时不会请求，避免阅后即焚把记录误删。文本分享只接受 26 位散列 ID，旧单词取件码不再兼容；单词码仅保留给文件分享的取件路由。

文件分享默认走实时直连：发送方创建会话，服务端生成 5 位数字取件码，同一时间只允许一个接收方加入，成功传输后关闭会话。服务端只保存会话元数据、SDP/ICE 信令和短期事件队列，按角色隔离令牌，长轮询取信令；文件内容通过 WebRTC DataChannel 从浏览器传到浏览器，不经过服务器磁盘或文件缓冲。连接建立后两端从 DTLS 指纹派生 4 位确认码，供双方核对，用来发现信令被替换。等待配对的会话 10 分钟过期，配对后的活动会话按 60 分钟滑动续期。创建和加入按 IP 限流；发送和轮询先验会话令牌，再按 IP 限流，匿名请求不能消耗他人额度。每个参与者的待取队列同时受 400 条与 256 KiB 限制；接收方离开时清空上一轮信令，新接收方从空队列开始。

默认使用公共 STUN，ICE 同时收集 IPv4 与 IPv6 候选。`PABU_RTC_ICE_SERVERS` 可以加入自建 TURN 地址，TURN 凭据由 `PABU_RTC_TURN_SECRET` 按 coturn REST 格式动态生成，有效期由 `PABU_RTC_TURN_TTL` 控制，公开配置接口不会下发静态用户名密码。发送端以 16 KiB 分片可靠有序发送，分片上限按 `sctp.maxMessageSize` 夹取，用 1 MiB 发送窗口做背压，读取提前一片与发送重叠。进度区读取 `getStats`，显示候选对类型、RTT 与按秒吞吐，可以直接分辨局域网直连、NAT 打洞和 TURN 中继。实时单文件上限由 `PABU_RTC_MAX_FILE` 调整，默认 256 MiB；接收端默认在内存中重组分片，也可以在传输前或传输中选择保存位置，边收边写入磁盘，此时不受内存上限约束。超级搜索框把任何 5 位数字都当作实时取件码，需要搜索 5 位数字时按 Esc 取消识别后回车。

直连失败时由发送方选择回退到服务器中转，走同一条端到端加密边界：浏览器把文件切成 4 MiB 分片，逐片用 AES-GCM 加密后上传，服务端按序号写入 `transfers/<code>.bin`，只保存密文。元数据与取件凭据留在内存，取件凭据只通过 `X-Pabu-Grant` 请求头传递。上传完成后可凭 PIN 换取一次性凭据，下载完成即删除密文文件。默认单文件 64 MiB、总容量 256 MiB，可用 `PABU_TRANSFER_MAX_FILE`、`PABU_TRANSFER_MAX_TOTAL`、`PABU_TRANSFER_MAX_ENTRIES` 和 `PABU_TRANSFER_CHUNK_SIZE` 调整。未完成的上传超过 1 小时由清理任务回收，进程启动时会清空整个 `transfers/` 目录。中转完成后，发送方会把单词取件码通过原信令会话送回接收方，接收方自动跳到文件取件页。文件取件页为 `/f/<code>`，`/p/<code>` 在命中文件分享时重定向到该页。

## 网站图标与抓取

导航书签默认不显示图标。用户开启「显示图标」后，由 `public/bookmark-icons.js` 为首页和管理员画布按可视区域加载图标，最多并发 4 个任务；同一站点的自动图标按规范化 origin 合并，自定义图标 URL 使用独立键。显示尺寸、裁剪、圆角和首字母兜底沿用书签样式。

图片和少量状态保存在独立 Cache Storage `pabu-bookmark-icons-v1`，缓存只属于当前浏览器，不含导航身份或用户清单。端侧内存及持久缓存按 LRU 限制为最多 500 条、32 MiB，单张图片最多 2 MiB；失败记录 7 天未访问后清理。新鲜图标 30 天内不自动检查，过期时保留旧图并尝试更新；离线时读取本机缓存。取消或网络限流不会覆盖成功图片。清除本机图标缓存不会删除服务器图标。

公网自动请求使用 `/api/icon?url=<origin>`。同一 Pabu 实例的所有匿名用户按 origin 共享内存和 `.icon-cache/` 磁盘缓存，不维护每个用户的图标副本，也不读取书签清单。服务端缓存最多 500 条、32 MiB 内存和 1000 条、64 MiB 磁盘，成功验证 7 天有效；过期时立即返回已缓存图片并合并后台更新。手动刷新等待共享任务完成，每 origin 60 秒内最多一次。网页头部最多读取 256 KiB，manifest 最多读取 64 KiB，最多验证 6 个声明图标或标准路径候选；未成功时只有在显式配置第三方回退后才调用所选供应商。最多跟随 3 次重定向，图片响应最多 2 MiB，任务预算 20 秒。Node HTTP(S) 客户端单独使用 64 KiB 响应头上限和有界 keep-alive 连接池。

服务端只访问 HTTP/HTTPS 的 80 和 443 端口。DNS 结果须全部为公网地址，并将实际连接固定到已校验地址；每次重定向重新校验。私网、回环、链路本地、云元数据和保留地址一律拒绝。第三方 Google 与 DuckDuckGo 回退默认关闭，只有设置 `PABU_ICON_FALLBACK_PROVIDERS` 后才使用，供应商只收到规范化公网 origin。远端 SVG 作为图片返回时带 `nosniff` 和 sandbox CSP。

内网书签和用户自定义图标由浏览器直连，不经过服务端代理，也不把完整签名 URL 交给服务端或第三方。可选书签字段 `iconUrl` 随导航导入导出、口令同步和站点导航保存；图片数据与缓存状态不参与同步。HTTPS 页面访问 HTTP 内网图标时仍可能受浏览器混合内容或本地网络访问策略限制。 内网自动获取先以无凭据请求读取页面声明的同源图标，页面请求与读取共限 1.5 秒、HTML 上限 256 KiB；根路径跨域请求失败时尝试 `/web/` 入口。随后尝试根目录标准图标及 LuCI Argon、Bootstrap 常见路径，整体仍限 8 秒。成功的直连图片 URL 在本机缓存 30 天，复用前验证图片仍可加载；跨域图片未提供 CORS 时只保存地址，离线可用性取决于浏览器 HTTP 缓存。未允许跨域读取且使用动态图片路径的服务仍需自定义图标地址。

## 不包含的能力

Pabu 不包含服务器监控与 Go agent、私人收藏库、备忘与待办、时间线、微博热搜或 WebDAV 备份。对应前后端接口均不提供。
