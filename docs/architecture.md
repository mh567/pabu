# Pabu 架构

Pabu 是从 Nav Sylph 独立拆分的轻量导航服务。Node.js 22 运行 Express 服务，静态前端由同一服务提供。

## 导航与存储

- `public/navigation-schema.js` 在浏览器和服务端共同校验导航结构。
- 普通访客导航保存在 IndexedDB `pabu-personal`，管理员个人导航、默认模板草稿和已发布模板保存在 SQLite。
- 管理会话、导航版本、同步空间、设备授权、邀请码和幂等回执共用 `pabu.db`。
- SQLite 保留上游历史迁移步骤以维持编号，新增尾部迁移删除不适用的模块缓存、监控、备忘、待办、时间线和恢复记录表。Pabu 数据库仅保留会话、导航、同步空间及治理配置相关表。
- 管理会话 Cookie 为 `pabu_session`。管理写请求校验会话、同源信息和 `X-Pabu-Request` 请求头。

## 口令同步

口令不上传。浏览器派生连接证明，服务端以散列值定位空间，再签发设备令牌。同步导航数据保存在服务端，服务端可读取数据，不提供端到端加密。邀请码由管理员生成且一次性使用，Pabu 不提供开放注册。管理端仅展示空间状态、大小、版本和备注，不读取空间正文或设备凭据。

同步内容包括导航及搜索引擎配置。设备凭据保存在浏览器 IndexedDB，服务端的空间数据存于 SQLite。同步空间由管理员控制暂停、停用和删除。

## 临时分享

分享正文由浏览器使用 Web Crypto 加密后交给服务端，服务端只临时保存密文。PIN、有效期、取件次数和总容量由服务端校验。分享数据保存在内存，服务重启即清空。

## 不包含的能力

Pabu 不包含服务器监控与 Go agent、私人收藏库、备忘与待办、时间线、微博热搜或 WebDAV 备份。对应前后端接口均不提供。
