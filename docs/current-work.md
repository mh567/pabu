# 当前工作

## 目标

完成 Pabu 与 Habu 的独立拆分，提供独立的产品标识、版本、存储命名和部署说明。

## 完成情况

- 保留导航管理、本地配置、管理员默认模板、口令同步、邀请码治理、同步空间治理和临时加密文本分享。
- 移除服务器监控与 Go agent、私人收藏库、备忘与待办、时间线、微博热搜和 WebDAV。服务器端对应接口返回 404。
- 邀请码采用管理员签发的一次性策略，有效期 48 小时，不开放注册。
- Pabu 默认端口为 4001，管理会话 Cookie 为 `pabu_session`，SQLite 库为 `pabu.db`，访客 IndexedDB 为 `pabu-personal`，Service Worker 缓存使用 Pabu 标识。
- 版本从 `0.1.0` 开始。初始提交 `4de2dd8` 已推送到 `https://github.com/mh567/pabu` 的 `main`，并发布 v0.1.0；Release 不附带二进制包，部署通过仓库源码执行 `npm ci`。
- 新增根目录管理脚本 `pabu.sh`，提供一键安装、更新、启停、状态、日志、systemd 自启和卸载。安装与更新直接下载对应 Release tag 的源码包，不依赖 Release 附件；更新前备份并恢复 `.env`、`config.json`、`server-config.json`、`.admin-password.json` 和 `pabu.db*`。
- `README.md` 与 `DEPLOYMENT.md` 的部署章节改为脚本化流程。
- 管理入口从首页底栏移除，改为独立路径 `/admin`。后台页面隐藏首页内容并以整页呈现，支持直接登录、保存后留在后台，以及返回首页。
- README、PRODUCT、页面 meta、manifest 和帮助文案统一以导航编辑、多端同步与文本分享为核心功能。
- 修复 `pabu.sh` 在 systemd 单元已存在但未运行时无法停止手动进程的问题。启用和启动前会先清理手动进程，systemd 启动失败时输出 `systemctl status` 与最近 30 行 journal。
- 版本推进到 `0.2.0`，包含独立管理后台、统一管理脚本、站点文案和 Service Worker 缓存更新。
- `0.2.0` 之后修复管理员登录后同步入口被外观入口顶替的问题：同步入口始终保留，并始终操作本地导航。
- 站点导航收敛为 SQLite 的单一 `site` 文档。管理员在 `/admin` 的一比一画布中直接编辑，保存即发布；删除管理员个人导航和默认首页草稿/发布双阶段。首页始终使用用户本地导航，管理员登录不切换首页，也不暂停本地口令同步。
- 管理后台页签调整为站点导航、用户与数据、账户。用户与数据新增编辑同步空间备注和管理员重置设备，继续不读取空间正文与设备凭据。
- 数据库迁移推进到 v16，`published` 内容成为站点导航，旧 `admin/draft/published` 行和导航回执被清理。
- 版本推进到 `0.4.0`，后台站点导航改为一比一画布编辑，管理员会话与首页本地导航完全解耦。
- 按使用反馈移除底栏「外观」入口，明暗模式只在编辑设置中调整；编辑设置重排为搜索、外观、数据管理三块，窄屏单列。站点默认导航发布仍只影响新访客和主动重置，不覆盖已有本地导航。
- 版本推进到 `0.4.1`，底栏与编辑设置布局调整完成。
- 编辑设置细节修正：隐藏「仅保存在本机」成功提示，数据管理默认展开；自定义下拉支持再次点击收起，同时保留点击外部关闭。
- 搜索引擎下拉重做：玻璃材质、顶部小箭头、展开淡入、选项错峰入场，选中项使用强调色和勾标。
- 版本推进到 `0.4.2`，编辑设置细节和搜索引擎下拉交互优化完成。
- 搜索引擎与编辑设置下拉统一规范：宽度取触发控件宽度与 `120px` 的较大者，共享玻璃材质、圆角、内边距、展开动画和选项错峰节奏。搜索引擎下拉左缘按按钮实际位置动态对齐，不再依赖固定 `58px` 偏移。
- 版本推进到 `0.4.3`，下拉菜单设计规范统一完成。
- 搜索引擎下拉左缘改为按按钮实际位置读取，宽度规则收窄为 `max(触发控件宽度, 120px)`；引擎下拉 120px，设置下拉与触发按钮同宽。
- 版本推进到 `0.4.4`，下拉锚点和宽度修正完成。
- 首页「说明」精简为导航编辑、多端同步、文本分享三项，移除管理员登录不切换首页和主题说明；ego 实测确认面板只剩三项。
- 管理后台 7 个原生 select 全部套用同一下拉组件：站点外观与搜索的 3 个下拉与 140px 触发按钮同宽，用户与数据的 4 个筛选下拉 120px 宽，共享 12px 圆角、玻璃材质和 `dropdown-in` 入场动画。
- 版本推进到 `0.4.5`，管理后台下拉统一和首页说明精简完成。
- 邀请功能改为管理员可开关：关闭后访客只凭口令即可创建同步空间，开启时仍消耗一次性邀请码。开关落在 `sync_settings.invite_required`，迁移推进到 v17；关闭不删除已有邀请码，重新开启立即恢复限制。访客端根据 check 响应决定是否显示邀请码输入框。
- 版本推进到 `0.5.0`，可选邀请功能完成。
